# Video tutorials and step-by-step walkthroughs

Learn Bracket Control using short, practical examples. Each tutorial has a playable MP4, written steps and screenshots. Some also include a printable PDF.

## Set up a Discord server

**[Automatic Server Setup Wizard]({{ '/guides/tutorials/automatic-server-setup/' | relative_url }})** — Choose optional Discord channels and categories, review the proposed changes, apply the setup and check the saved configuration.

## Create and run a draft

**[Snake Draft tournament]({{ '/guides/tutorials/draft-tournament/' | relative_url }})** — Create the event, import free-agent players, confirm two captains, make alternating picks and verify the final rosters. Includes an illustrated PDF.

## Run a Double Elimination competition

**[Double Elimination BO3 and BO1]({{ '/guides/tutorials/double-elimination-bo3/' | relative_url }})** — Configure a winners-bracket BO3, losers-bracket BO1 and grand-final BO3; track bracket advancement and an optional reset final. Includes a printable PDF.

## Share directly with team captains

**[Captain score reporting — short video]({{ '/guides/tutorials/captain-score-reporting/' | relative_url }})** — Upload one scoresheet per game win, confirm or dispute the opponent's report and check the completed match. Share this page without requiring captains to read tournament setup instructions.

> **Demo scope:** These recordings use fictional teams and simulated Discord sign-in or connections. They demonstrate screen flows, not completed tests against a real Discord server. When running a live event, confirm permissions, channel visibility and notifications on your own server.

For the complete reference, use the [User guide]({{ '/guides/user-guide/' | relative_url }}), [Discord Server Setup]({{ '/guides/server-setup/' | relative_url }}), [Draft tournaments]({{ '/guides/drafts/' | relative_url }}), or [Match results]({{ '/guides/match-results/' | relative_url }}).
